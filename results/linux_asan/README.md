# Archived Linux/ASan experiment logs

Each timestamped directory keeps `summary.json` and the main CSV/metadata files readable on GitHub. `raw_logs.zip` in the same directory contains **every original file** from that completed experiment, including per-run stdout, stderr, exit codes, build logs and the same summary files. The logs were archived only to keep the GitHub browser upload below its per-upload file-count limit; measurements were not recalculated or edited.

To inspect a particular diagnostic or measurement, download that run's `raw_logs.zip` and extract it. The two timing directories each contain 108 original files; the memory directory contains 37. All three `STATUS.txt` files are `COMPLETE`.
